Privacy Policy for Vision Art Studio Bot

Effective Date: October 2026

1. Data Collection

Vision Art Studio bot collects minimal data required to function properly, including Discord User IDs, Server IDs, and message content specifically related to ticket commands and design orders.

2. Data Usage

The collected data is strictly used to process design tickets, manage roles, and deliver studio automation services. We do not sell, share, or distribute user data to any third parties.

3. Data Retention & Deletion

Data is retained only for as long as necessary to fulfill service requests. Server administrators or users can request data deletion by contacting us in our support server or deleting their tickets.

4. Contact

If you have any questions or concerns regarding this privacy policy, please contact us via our official Discord server support team.
